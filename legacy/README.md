# Historical fitting and experiment scripts

Preserved from the original combined ElChemTools package. These files are not loaded by
GPNPTPB. Imports and references to ElChemTools.simple_run, simulation descriptors and old
laboratory dataset names are historical, not promises of compatibility with the split packages.
The original environment is recorded here for reproducibility. Migrate these entry points
when model development resumes. Numerical model source remains active in ../src/models.
